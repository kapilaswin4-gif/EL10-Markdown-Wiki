Code of Conduct

Our Pledge

We are committed to providing a respectful and welcoming environment for everyone participating in this project.

Expected Behaviour

All contributors are expected to:

* Treat everyone with respect.
* Use polite and professional language.
* Accept constructive feedback.
* Respect different opinions.
* Help maintain a positive learning environment.

Unacceptable Behaviour

The following behaviours are not acceptable:

* Harassment or discrimination.
* Insulting or threatening other contributors.
* Sharing private information without permission.
* Disrupting discussions intentionally.

Reporting Issues

If you experience or observe inappropriate behaviour, please report it to the project maintainer.

Contact: Replace this line with your own GitHub username or an email address you are comfortable sharing for project-related communication.

Enforcement

Project maintainers may review reported incidents and take appropriate action to maintain a respectful environment.

Scope

This Code of Conduct applies to project discussions, contributions, issues, pull requests, and other project-related activities.
